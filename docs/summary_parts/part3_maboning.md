## 3. 经验与问题
# 个人开发经验与遇到的问题总结（马伯宁）

## 一、本次开发收获与经验
1. 熟悉了 Git 协作流程：分支创建、提交、拉取、合并申请等完整操作。
2. 提升了文档编写能力，学会了使用Vi工具，cat命令进行文本编辑
3. 可以排查一些问题，遇到报错能通过提示信息逐步解决。

## 二、开发过程中遇到的问题
1. 完成自己任务时总是忘记pull最新的dev分支，导致数据不统一
2. 不小心推错分支，学会了通过关闭PR撤回操作。
3. 对 checkout -b、pull、merge 等命令不熟悉，通过实践逐步掌握。

## 三、解决方法与总结
1. 遇到代码冲突不要慌，先拉取最新代码再合并。
2. 提交前确认当前所在分支，避免推错。
3. 常用 Git 命令多练习，形成肌肉记忆。
